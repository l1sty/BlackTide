# Black Tide

## Управление магазином

Откройте `/admin` и введите пароль администратора. Во вкладке «Товары» можно менять ассортимент, цены, статусы, размеры, замеры и фотографии. Во вкладке «Предоплата» доступны реквизиты и тексты на двух языках. Кнопка «Сохранить» публикует изменения в магазине. При одновременном редактировании панель предупреждает о конфликте.

## Подключение на Vercel

1. Создайте базу libSQL в Turso и выпустите токен с правом записи.
2. В **Settings → Environment Variables** проекта Vercel добавьте `TURSO_DATABASE_URL`, `TURSO_AUTH_TOKEN`, `ADMIN_PASSWORD` и `ADMIN_SESSION_SECRET` для Production. Задайте уникальный пароль и отдельный случайный секрет (например, вывод `openssl rand -hex 32`). Для Preview используйте отдельную базу.
3. Выполните Redeploy и откройте `/admin` на домене магазина. При первом подключении таблицы создаются автоматически и заполняются текущим каталогом. Данные и загруженные фото сохраняются в базе между развёртываниями.

Без подключения базы на Vercel витрина продолжает работать с каталогом из репозитория, а вход в панель закрыт.

## Локальный запуск

Используйте Node.js 22.13+ и выполните `npm ci`. Скопируйте `.env.example` в `.env.local`, задайте `ADMIN_PASSWORD` и `ADMIN_SESSION_SECRET`, затем выполните `npm run dev`. По умолчанию локальные данные хранятся в `.data/black-tide.sqlite`.

Для отправки заказов укажите `TELEGRAM_BOT_TOKEN` и `TELEGRAM_CHAT_ID`. Для справочника Новой Почты при необходимости укажите `NOVA_POSHTA_API_KEY`.
